# Tfet-based-oscillator
Design and analysis of GaSb/Si heterojunction-based vertical TFETs using Silvaco TCAD, with source-pocket engineering and planned oscillator implementation in Cadence Virtuoso.

Design and Analysis of TFET-Based Oscillator Using Silvaco TCAD and Cadence Virtuoso

📌 Project Overview

This project focuses on the design and analysis of Tunnel Field-Effect Transistors (TFETs) for low-power VLSI applications. The study investigates GaSb/Si heterojunction-based Dual-Metal Double-Gate Vertical TFETs (DM-DG-VTFETs), with and without source-pocket engineering, using Silvaco TCAD simulations.

The project also explores a proposed source-heterojunction structure to improve key transistor performance parameters, including ON-state current, OFF-state current, ON/OFF current ratio, and subthreshold swing.

The next phase involves developing compact device models and implementing a TFET-based oscillator in Cadence Virtuoso.

🎯 Objectives

- Design and simulate GaSb/Si heterojunction-based vertical TFET structures.
- Analyze n-type and p-type TFET configurations.
- Investigate the effect of source-pocket engineering on device performance.
- Study electrical characteristics using transfer characteristics and energy band diagrams.
- Extract and compare important device parameters.
- Explore a source-heterojunction-based TFET structure for improved performance.
- Develop compact models and investigate oscillator implementation using Cadence Virtuoso.

🛠️ Tools and Technologies

- Silvaco TCAD / ATLAS – Semiconductor device structure design and simulation
- Cadence Virtuoso – Planned circuit-level design and oscillator implementation
- Verilog-A – Planned compact device modelling

🔬 Device Configurations

The following device configurations are investigated:

1. N-type GaSb/Si dual-metal double-gate vertical TFET without a source pocket
2. N-type GaSb/Si dual-metal double-gate vertical TFET with a source pocket
3. P-type GaSb/Si dual-metal double-gate vertical TFET without a source pocket
4. P-type GaSb/Si dual-metal double-gate vertical TFET with a source pocket
5. Proposed source-heterojunction-based vertical TFET structures

⚙️ Methodology

1. Define the device geometry, doping concentrations, gate work functions, and material parameters.
2. Construct the vertical TFET structures in Silvaco TCAD.
3. Configure relevant physical models, including non-local band-to-band tunnelling (BTBT), Shockley–Read–Hall (SRH) recombination, and bandgap narrowing.
4. Simulate the electrical characteristics of the devices.
5. Analyze transfer characteristics, energy band diagrams, and capacitance characteristics.
6. Extract key performance metrics and compare the simulated results with reference devices.
7. Explore compact modelling and circuit-level oscillator implementation as the next stage of the project.
